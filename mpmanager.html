MP Manager

A free dual pane, Material Design file manager for Android with focus on APKs and the goal to be an open source alternative to MT Manager.

Download GitHub ★ ~ Telegram Discussion

Overview

MP Manager is a free, open source, dual pane file manager for Android built on Material Design principles. It is designed as a practical alternative to MT Manager, with particular attention paid to working with APKs, archives and native Android storage.

Everything below is grouped by area. Each feature card includes a description, what it does in practice, and a button that opens the screenshots in a lightbox where one exists. The two panes allow files to be moved, copied or compared side by side without leaving the screen.

File Manager

The core of the app: navigating and managing files across two panes, with archiving, searching, root access and a built-in viewer for common formats.

Dual pane navigation

Browse two folders side by side, making it easy to move or copy files from one pane to the other. Each pane is independent, so you can keep a source open in one pane while working in a destination in the other.

  • Separate home folder for each pane
  • Back and forward buttons
  • Sync both panes to the same folder
  • New file/folder and parent folder buttons
  • Pull down to refresh the current folder
  • Optionally highlight the active pane with a coloured, animated border

Bookmarks and history

Add any folder to bookmarks and manage them from a bottom drawer that opens by swiping up on the bottom bar. The drawer holds tabs for your bookmarks and your navigation history.

  • Organise bookmarks into groups, edit and delete them by long pressing
  • Choose which tab new bookmarks are added to
  • Reorder bookmarks with drag and drop
  • Optionally show bookmarks and groups in the sidebar

Filtering, sorting and hidden files

Control how the current folder is presented. You can filter as you type, choose a sort order, and decide which files stay out of sight.

  • Filter the current folder as you type
  • Sort by name, size, date or type, with reverse order
  • Apply a sort to the current folder only or everywhere
  • Hide files and show or hide system dot folders
  • Edit the list of manually hidden files later

Advanced search

Search the current folder by file name, optionally recursing into subfolders. Results open in a persistent panel that stays on screen while you work, so you can open several matches in a row.

  • Match case and regular expressions
  • Search for text inside file contents, including inside ZIP and APK archives
  • Set a minimum or maximum file size
  • Recent searches saved for quick reuse
  • Persistent results with real-time progress and a stop button
  • Save edits made from search results back into the APK

File operations

Everyday file management with progress reporting, plus batch operations that scale up to many files at once.

  • Create, rename, copy, move and delete files and folders with progress reporting
  • Extract archives and add files to ZIP and APK, with an auto sign and zipalign option for APKs
  • Rename several files at once with templates using prefix, suffix, numbering and find/replace, with a preview
  • Resolve conflicts with replace, skip or rename across all remaining files
  • Keep the original modification date when copying, and edit dates in properties

Archives and built-in viewers

Archives are handled as first class citizens. Browse them directly, including nested archives, without extracting first. MIUI and Android backup files are recognised and read correctly.

  • Browse archives and backups directly, including nested ones
  • Support for MIUI and Android backup (.bak) archives, handled by original extension
  • Open PDF files in a built-in viewer
  • Preview fonts and view HTML files
  • Open, edit or execute shell scripts, optionally with root, showing output and exit code

File properties and sharing

Inspect a file's details from a single dialog, including checksums, permissions and the MIME type detected from the file contents.

  • View type, size and last modified date, and copy any value with a long press
  • Edit the name and last modified date inline with a picker
  • Compute, verify and compare checksums, with CRC32 for ZIP entries
  • With root, edit permissions, owner, group and special flags
  • Share files or open them with another app, and set or clear a default app per type
  • Show signature details on press for signed files

Root and Shizuku file management

Browse and manage files that are normally off limits, including Android/data, obb and media on Android 11+. With Shizuku you can also read locations the shell can access but the app cannot, such as system folders.

  • Access Android/data, obb and media folders
  • With Shizuku, open locations like /storage/emulated and system folders, read-only where modification is not permitted
  • Cached root listing for speed, safe on paths with spaces
  • Editors write back through root when needed
  • Root directory added to the sidebar in root or Shizuku mode

DocumentsProvider viewer

Browse app data folders through the Storage Access Framework without root. DocumentsProviders on the device are listed in a dedicated tool and can be opened in a pane like a regular folder.

  • List installed DocumentsProviders in Tools → Documents providers
  • Open a provider in a pane like a normal folder
  • Reach locations granted via providers, including ones injected by patchers

Customizable file menu

Reorder the long press file menu by dragging items anywhere, so the actions you use most are where you expect them.

  • Reorder menu items with drag and drop
  • Show the menu as a bottom sheet or in two columns
  • Uses Material colours consistent with the theme

Media

Audio, video and images play in the app, so you do not need to switch away to preview or inspect a file.

Built-in audio and video player

Play audio and video files without leaving the app. A mini player with artwork, seek bar and controls plays in the background or expands into a full player.

  • Mini player dialog that can play in the background
  • Expands into a full player
  • Fast startup with background loading of sibling tracks
  • Swipe to seek video frames during playback
  • Keep the screen on and set the skip duration in settings

Image viewer and editor

Open images with swipe between pictures in the directory. EXIF metadata is shown for supported files, and images can be deleted or shared from the viewer.

  • Swipe between pictures in the directory
  • EXIF metadata shown, and editable, for supported files
  • Crop single or multiple images with standard or lossless JPEG quality
  • Rotate, flip and strip EXIF metadata in single or batch mode

APK Tools

The most distinctive part of MP Manager. Everything from inspecting and installing an APK to signing, patching, decompiling, dumping and deduplicating it.

APK information and install

Tap an APK to see its icon, name, version code and name, package name, signature schemes used (V1, V2, V3, V4) and whether it is protected. Full signature details can be shown on press. Both regular and split APKs can be installed.

  • View files inside the APK
  • Install regular and split APKS
  • For installed packages, APK and data directories shown with root
  • Show signature details on press
  • Candidate version code shown beside the version name

Sign APK and split APKs

Sign APKs and split APKs with your own or default (Debug) key. Signing supports JKS and PKCS12 keystores as well as PK8/PEM keys, and new keys can be generated inside the app.

  • JKS and PKCS12 keystores, plus PK8/PEM keys
  • Generate new keys inside the app
  • Toggle and configure automatic signing after modification
  • Use biometrics instead of entering the password each time

Decompile, build and protect

All functions from REAndroid APKEditor are available: decompile an APK, build an APK from a decompiled folder, merge (AntiSplit), refactor obfuscated resource names and protect.

  • Decompile an APK
  • Build an APK from a decompiled folder
  • Merge split APKs (AntiSplit), choosing which splits to include
  • Refactor obfuscated resource names and protect
  • Set compression level and sign the merged APK automatically

Quick edit APK attributes

Change common attributes quickly in a dialog, or edit the manifest deeply from a tree view. A .bak backup is created on edit and can be restored.

  • Change launcher icon, app name, install location, version code and name, min SDK and target SDK
  • Edit every activity and property in the manifest from a tree view, including disabling entries

APK optimization and cloning

Optimize APKs by removing chosen files, with a default list of common tracker and metadata files that can be edited. You can also clone an APK with a new package name.

  • Optimize APKs by removing chosen files
  • Edit the default list of common tracker and metadata files
  • Clone an APK with a new package name

Dex editing

Edit dex files with DEX Editor Pro. When editing a dex file inside an APK you can choose which dex files to load. Saving asks whether to add the modified file back into the APK and sign it, with a .bak backup created.

  • Choose which dex files to load when editing inside an APK
  • Import and edit .class and .smali files with folder navigation
  • Fast dex to smali conversion without extracting the APK
  • Improved search with find usages and find overriding methods

ARSC editing

Edit resources.arsc with the built-in ARSC Editor or ARSC Editor Plus. Search by resource value or ID, browse the string pool, and get automatic backups on save.

  • Search by value or ID, copy IDs and jump to an ID
  • Browse the string pool and TEXT tab
  • ARSC Editor Plus translation mode with side-by-side editing
  • Batch import and export of entries and whole string pools
  • Floating resource querier for names, IDs and colour values

Xposed patcher

Patch an APK with NPatch or LSPatch in integrated mode. An Xposed loader is embedded so selected modules run standalone without a manager app, and the output is signed with the key under Sign Settings.

  • Choose NPatch or LSPatch engine and a signature bypass level
  • Embed module APKs so the patched app runs standalone
  • Per-engine options: MicroG redirect, hiding libs, forcing cleartext traffic, overriding target SDK or version code, and more
  • Save, load and delete patch profiles
  • Inject a DocumentsProvider for file picker access to app data

APK data multiplexing

Multiplex (deduplicate) an APK by redirecting entries that are byte-identical to entries inside the stored embedded APK, so duplicated data is stored only once and the file shrinks.

  • Reduce the size of patcher outputs and similar packages
  • Signed in place with the V2/V3 raw-file signer using your key
  • Preserves the deduplication after signing

IL2CPP runtime dumper

Dump Unity IL2CPP games at runtime without root or hooking. libil2cppdumper.so is injected into the APK and loaded from a chosen class. When the patched app runs, it writes a C#-like dump of every managed type plus IDA/Ghidra scripts.

  • Choose an injection point (Application class or an activity)
  • Writes dump.cs plus IDA/Ghidra scripts (script.json)
  • No hooking or root needed on the target
  • Optionally expose the dump through a DocumentsProvider

Native library patcher

Patch native .so libraries with instruction stubs (port of LibPatcher) so a function returns a fixed value. Enter hex offsets from Ghidra, IDA or r2.

  • Patch boolean, integer, long, float, double or void return values
  • Enter multiple hex offsets separated by commas
  • Supports armeabi-v7a and arm64-v8a

Editing and Comparing

Full featured text, hex and comparison tools for working with code, resources and binary files.

Text editor

A full text editor based on Sora Editor with a customizable bottom bar, regex find and replace, and many editor features. Multiple files can be open at once in tabs.

  • Syntax highlighting, jump to line, word wrap and a read only mode
  • Regex find and replace with previous/next navigation
  • Line actions: duplicate, delete and case conversion, comment toggling
  • Method and field list, with click, long press and extra button actions
  • Binary Android XML (AXML) files decoded for editing and re-encoded on save

Hex editor

View and edit any file in hex with goto offset, search and selectable encodings. Changes can be saved back directly.

  • Goto offset, search and selectable encodings
  • Paste data from hex, decimal, binary, ASCII or base64 text
  • Search and replace as string, integer or other data types in either endianness
  • Revert unsaved changes

Compare tools

Compare two text files, two ZIP/APK files, two resources.arsc files, or two dex files. Select one item in each pane and the matching compare option appears in the file menu.

  • Dex comparison summarises added, removed and changed classes
  • Ignore debug info, optimizations, register counts and nop instructions
  • Show differences side by side or unified with navigation
  • Export and import Dex comparison results in MT-compatible .mtcr format

APK Extractor

Extract installed apps and their parts, manage apps and merge split APKs, all from one list.

Extract and share APK parts

Extract APKs in batch and pull out specific parts: the app icon, resources.arsc, classes.dex, AndroidManifest.xml, base.apk, splits and native libs, as well as the launch activity. Split APKs can be merged into a single APK before extracting, and anything can be shared directly.

  • Merge split APKs into a single APK before extracting
  • Share anything directly
  • Pull down to refresh the app list
  • With root, launch through an activity picker, stop, disable or enable apps, clear data or uninstall
  • Badges for split APKs and app data directories

FTP

Run a server on the device or connect to a remote one, with profiles for quick reuse.

FTP server

Use FTP server with a custom port, username and password, with optional FTPS explicit or implicit TLS. The server keeps a notification while running so it can be stopped easily.

  • Custom port, username and password
  • Optional FTPS explicit or implicit TLS
  • Notification while running so it can be stopped easily
  • Save connection settings as profiles
  • Copy or share the device IP

FTP client

Connect to an FTP server with optional FTPS and browse remote folders in either pane, with the same navigation controls as local files. Files can be uploaded from the device.

  • Browse remote folders in either pane with the same navigation controls as local files
  • Upload files from the device
  • Save connection details as profiles to connect to multiple devices easily

Utilities

Supporting tools for picking colours, inspecting layouts, running commands, managing storage and customising the app.

Screen color picker

Use a floating overlay to find out colors anywhere on the screen.

Layout inspector

Inspect the view hierarchy of any app through a floating overlay window.

Command Helper

Create templates for commands that can be quickly applied to any selected file, generated for several files at once, and previewed, copied or run in Termux.

  • Create command templates with placeholder variables
  • Generate commands for several files at once and preview them
  • Copy or run them in Termux, one by one or all at once
  • Run command line tools like dex2c on files via MP Manager

Plugins and tool packs

Plugins install as regular apps and are listed in a hub, together with tool packs downloaded in the app. Each plugin runs in its own process and permissions, and its certificate is verified on first use.

  • Plugins add entries to the sidebar, settings, file menu, text editor or APK dialog
  • Tool packs group Media, Device, Network, Math, Text and Code, Notes and Random tools
  • Trust, disable, update or remove plugins, or give them a launcher shortcut
  • Refresh the pack catalog and change the hosting server

Wi-Fi Manager

Shows the current connection with link speed, gateway, IP and MAC details, together with data usage for the device and the app.

  • Read, search, export or share saved Wi-Fi passwords with root, including as a QR code
  • Switch private DNS between saved profiles with one tap
  • Quick settings tile cycles the profiles

Storage Manager

Shows mounted volumes with used and free space, the space used by files grouped by type, and the largest files on the device, which can be filtered by type and deleted.

  • Space used by file type
  • Largest files on the device, filterable and deletable
  • List and clear app caches with root or accessibility service

Appearance and storage info

Control how the app looks and behaves, and see storage usage in the sidebar.

  • System, light, dark and black themes with Material Theme and Dynamic Colors
  • Custom fonts for the app and dialogs, adjustable list size and date/time format
  • Show folder size in the file list: always, only in archives, or never
  • Sidebar shows mounted storages with used and free space
  • Language can be picked manually, with automatic update checking
