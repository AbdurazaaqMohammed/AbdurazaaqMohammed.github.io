File Manager

Dual pane navigation

Browse two folders side by side, making it easy to move or copy files from one pane to the other.

  • Separate home folder for each pane
  • Back and forward buttons
  • Sync both panes to the same folder
  • New file/folder button
  • Parent folder button

Bookmarks and history

Add any folder to bookmarks and manage them from a bottom drawer.

  • Opens by swiping up on the bottom bar
  • Tabs for bookmarks and navigation history
  • Delete a bookmark by long pressing on it

Filtering, sorting and hidden files

  • Filter the current folder as you type
  • Sort by name, size, date or type, with reverse order
  • Choose whether a sort applies to the current folder or everywhere
  • Hide files from the list and show or hide system hidden files (dot folders)
  • Edit the list of manually hidden files later

Advanced search

Search the current folder by file name, optionally recursing into subfolders.

  • Match case and regular expressions
  • Search for text inside file contents
  • Set a minimum or maximum file size
  • Recent searches saved for quick reuse

File operations

  • Create, rename, copy, move and delete files and folders with progress reporting
  • Extract archives and add files to ZIP and APK archives, with an auto sign option for APKs
  • Rename several files at once using templates with prefix, suffix, numbering and find/replace

File properties and sharing

  • View type, size and last modified date
  • Long press to copy any value to the clipboard
  • Share files or open them with another app

Media

Built-in audio and video player

Play audio and video files without leaving the app.

  • Mini player dialog with artwork, seek bar and playback controls
  • Plays in the background or expands into a full player

Image viewer

  • Swipe between pictures in the directory
  • EXIF metadata shown for supported files
  • Delete or share images from the viewer

APK Tools

APK information and install

Tap an APK to see its icon, name, version code and name, package name, signature schemes used (V1, V2, V3, V4) and whether it is protected.

  • View files inside the APK
  • Install regular and split APKS

Sign APK and split APKs

  • Sign APKs and split APKs with your own or default (Debug) key
  • JKS and PKCS12 keystores, plus PK8/PEM keys
  • Generate new keys inside the app
  • Toggle and configure automatic signing after modification
  • Option to use biometrics instead of entering the password every time

Decompile, build and protect

All functions from REAndroid APKEditor are available:

  • Decompile an APK
  • Build an APK from a decompiled folder
  • Merge (AntiSplit)
  • Refactor obfuscated resource names
  • Protect

Quick edit APK attributes

  • Change launcher icon, app name, install location, version code and name, min SDK and target SDK in a dialog
  • Edit every activity and property in the manifest from a tree view, including disabling entries

APK optimization and cloning

  • Optimize APKs by removing chosen files
  • Edit the default list of common tracker and metadata files
  • Clone an APK with a new package name

Dex editing

Edit dex files with DEX Editor Pro by developer-krushna.

  • Choose which dex files to load when editing inside an APK
  • Saving asks whether to add the modified file back into the APK and sign it
  • A .bak backup is created when an APK is modified

Editing and Comparing

Text editor

A full text editor based on Sora Editor.

  • Customizable bottom bar
  • Regex find and replace
  • Binary Android XML (AXML) files decoded for editing and re-encoded on save automatically

Compare tools

  • Compare two text files
  • Compare two ZIP/APK files
  • Compare two resources.arsc files

Select one item in each pane and the matching compare option appears in the file menu.

APK Extractor

Extract and share APK parts

Extract APKs in batch and pull out specific parts: the app icon, resources.arsc, classes.dex, AndroidManifest.xml, base.apk, splits and native libs, as well as the launch activity.

  • Merge split APKs into a single APK before extracting
  • Share anything directly

FTP

FTP server

  • Custom port, username and password
  • Notification while running so it can be stopped easily
  • Save connection settings as profiles
  • Copy or share the device IP

FTP client

  • Browse remote folders in either pane with the same navigation controls as local files
  • Upload files from the device
  • Save connection details as profiles to connect to multiple devices easily

Utilities

Screen color picker

Use a floating overlay to find out colors anywhere on the screen.

Layout inspector

Inspect the view hierarchy of any app through a floating overlay window.

Command Helper

  • Create templates for commands that can be applied to any selected file
  • Generate commands for several files at once
  • Preview, copy or run them directly in Termux
  • Quickly run command line tools like dex2c on files via MP Manager

Appearance and storage info

  • System, light, dark and black themes with Material Theme and Dynamic Colors
  • Sidebar shows mounted storages with used and free space
