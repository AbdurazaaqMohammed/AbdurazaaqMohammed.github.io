# [Abdurazaaq Mohammed](https://abdurazaaqmohammed.github.io)

Personal website and browser based tools I developed.

### [Transcriber](https://abdurazaaqmohammed.github.io/transcriber)
A simple GUI to aid in using free APIs to transcribe audio, summarize text and turn it into beautiful images or presentations.

- **Transcribe** - Chunked transcription allowing transcribing long audio using Gemini or Whisper.
- **Summarize** - in various formats and with targets for length.
- **Visualize** - Turn long text into presentation or short text into a single image, with several themes.
- **Profiles** - Save your favorite settings and models.

Note: Files are sent to the model providers for processing with no other transfer or storage.

Note: Designed with idea to transcribe Islamic lectures in mixed Arabic and English
